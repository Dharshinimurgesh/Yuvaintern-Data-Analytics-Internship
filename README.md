# Yuvaintern Data Analytics Internship

## Week 1 Data Acquisition Cleaning and Preprocessing

This repository contains my Week 1 internship task on data acquisition, data cleaning, and preprocessing using the Titanic Survival Prediction dataset.

### Work Completed

- Acquired the publicly available Titanic dataset.
- Explored dataset structure, data types, and missing values.
- Handled missing values in Age, Cabin, and Embarked columns.
- Checked duplicate records and invalid values.
- Detected outliers using the IQR method.
- Applied log transformation to reduce Fare skewness.
- Performed feature engineering using Deck, Title, FamilySize, and IsAlone.
- Prepared features using encoding and scaling.

## Week 2 Exploratory Data Analysis and Visualization

This section contains my Week 2 internship task on Exploratory Data Analysis and visualization using the cleaned Titanic Survival Prediction dataset.

### Work Completed

- Performed initial dataset exploration using data types, descriptive statistics, missing-value checks, and duplicate-record checks.
- Analysed the overall passenger survival rate.
- Visualised survival patterns by gender and passenger class.
- Examined age and fare distributions.
- Analysed survival rates by age group, embarkation port, and family size.
- Created a correlation heatmap to study relationships between numerical variables.
- Generated labelled charts using Pandas, Matplotlib, and Seaborn.
- Documented findings using actual calculated values from the dataset.

### Week 2 Files

- `week2_titanic_cleaned_eda.ipynb` - Executed EDA notebook with visualizations.
- `Dharshini_M_Week_2_EDA_Report.docx` - Week 2 EDA report.
- `titanic_cleaned.csv` - Dataset used for the analysis.

### Key Findings

- Overall survival rate: 38.38%.
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had the highest survival rate.
- Fare distribution was right-skewed because of a few high-value tickets.
- Passenger class, gender, fare, and family size showed meaningful relationships with survival.
